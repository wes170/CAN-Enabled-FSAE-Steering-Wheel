# Sharp LS027B7DH01 — 2.7" memory LCD, mechanical model

`LS027B7DH01.step` is a STEP AP214 model of the display module, generated by
`ls027b7dh01.py` (CadQuery). Every dimension traces to Sharp spec
**LCP-2110015A** (LS027B7DH01 specification, Rev. Jun 2010) — section 3
"Mechanical Specification" and Figure 8-1 "Outline Dimension".

![preview](preview.svg)

The part is `LS027B7DH0` on some distributor listings; the full Sharp model
number is `LS027B7DH01` (and `LS027B7DH01A` for the RoHS/Avnet variant, which
is mechanically identical).

## Coordinate system

| | |
|---|---|
| Origin | active-area centre, on the front (display) surface |
| +X | right, viewed from the front |
| +Y | up, viewed from the front |
| +Z | out of the display, toward the viewer |

The module occupies **Z = 0 down to Z = −1.64**, so mating a bezel to the
display face is just `Z = 0`.

The active-area centre is exactly the horizontal centre of the glass (31.4 mm
from either edge), but sits 19.64 mm below the top edge and 23.18 mm above the
bottom edge. Sharp dimension both of those distances on Figure 8-1, so this is
the datum the datasheet itself works from — the bezel window is concentric
with the origin in X and Y.

Overall bounding box: **62.80 (X) × 56.60 (Y) × 1.64 (Z) mm**, where Y includes
the flat FPC tail. Glass only is 62.80 × 42.82 × 1.64.

Key stations:

| Feature | Coordinate |
|---|---|
| Glass top edge | Y = +19.64 |
| Glass bottom edge | Y = −23.18 |
| Active area | X ±29.40, Y ±17.64 |
| FPC tip | Y = −36.96 |
| Front surface / rear surface | Z = 0 / Z = −1.64 |

## Bodies

The STEP is a named, coloured assembly of 8 components:

| Name | Size | Z range |
|---|---|---|
| `active_area` | 58.8 × 35.28 | 0 → −0.23 |
| `polarizer_front` | 62 × 40.42, active window cut out | 0 → −0.23 |
| `glass_front` | 62.8 × 41.22 | −0.23 → −0.83 |
| `glass_rear` | 62.8 × 42.82 | −0.83 → −1.53 |
| `polarizer_rear` | 62 × 40.42 | −1.53 → −1.64 |
| `fpc` | 0.10 thick film | −0.73 → −0.83 |
| `fpc_stiffener` | 5.5 × 4.0 PI | −0.53 → −0.73 |
| `fpc_contacts` | 10 × 0.35 × 3.5, recessed into the film | −0.80 → −0.83 |

`active_area` is a separate solid rather than a marking, so the display window
is directly selectable/measurable in CAD. It is cut out of `polarizer_front`,
so no two solids overlap.

Measured off the Figure 8-1 vector geometry, because Sharp draw them but do
not attach a callout:

| Value | Model | How |
|---|---|---|
| FPC free length past the glass edge | 13.78 | tip at 56.60 below the glass top, glass ends at 42.82 |
| Taper start | 46.49 below the glass top | wide section's lower end |
| FPC base film thickness | 0.10 | film drawn 0.100 in the side view |
| PI stiffener thickness | 0.20 | drawn 0.201; 0.10 + 0.20 = the dimensioned 0.3 ±0.03 |
| Contact plating thickness | 0.03 | modelled recessed into the film, not proud of it |

The 0.3 ±0.03 callout is the **total** insertion thickness at the contact end
(film + stiffener), which is what the recommended connectors expect — both
Molex 51441-1093 and SMK CFP-4610-0150F take a 0.30 mm FPC. The model keeps
the tip at exactly 0.30.

### The front glass is shorter than the rear glass

Worth knowing if you are designing a bezel or a compression gasket: the front
(counter) glass is **1.6 mm shorter** than the rear (TFT) glass. That step
exposes a ledge along the bottom edge of the rear glass, and the FPC is
ACF-bonded onto it. Because the FPC + stiffener stack is 0.30 mm and the front
glass it sits beside is 0.60 mm, **the tail never protrudes past the module's
1.64 mm envelope** — it sits inside the cavity the shorter front glass leaves.
So the module is a clean 1.64 mm slab everywhere, and the flat tail adds no
thickness.

## Cross-check

Re-importing the exported STEP gives 17 solids, all reported valid by
`BRepCheck_Analyzer`, with an overall bounding box of exactly
62.800 × 56.600 × 1.640.

As an independent check on the layer stack, the modelled glass volume
(3435 mm³) and film volume (852 mm³) at typical alkali-free glass (2.50 g/cm³)
and TAC/PVA polarizer (1.35 g/cm³) densities predict **9.74 g** against the
datasheet's **9.9 g typ** — 1.6% low, which is about what you would expect
from ignoring the ACF bond, the liquid crystal layer, and the FPC copper.

## Simplifications

- The FPC is modelled **flat, as shipped**. Section 8-2 allows folding it back:
  bend only in the band 0.8–6.0 mm from the glass edge, inner radius ≥ R0.45,
  never toward the polarizer, ≤ 3 bend cycles. If you fold it in CAD, fold it
  yourself — the model does not.
- The R0.2 / R0.6 notches on the FPC edges at the taper are omitted; the tail
  is drawn as wide section → straight taper → neck.
- The ACF bond bead, the liquid crystal layer, and the serial-number label
  (Figure 11-1) are not modelled.
- The glass layers are modelled at full 62.8 mm width. Figure 8-1 dimensions no
  width step between the front and rear glass, only the 1.6 mm height step.

## Pinout

Table 4-1. **Pin 1 is on the right viewed from the display side**, i.e. on the
left viewed from the contact (rear) side — the model's `fpc_contacts` follow
that, pin 1 at +X.

| Pin | Name | I/O | Function |
|---|---|---|---|
| 1 | SCLK | IN | Serial clock |
| 2 | SI | IN | Serial data in |
| 3 | SCS | IN | Chip select |
| 4 | EXTCOMIN | IN | External COM inversion (H = active) |
| 5 | DISP | IN | Display on/off (L = all white, memory retained) |
| 6 | VDDA | PWR | Analog supply |
| 7 | VDD | PWR | Digital supply |
| 8 | EXTMODE | IN | COM inversion mode select |
| 9 | VSS | PWR | Logic ground |
| 10 | VSSA | PWR | Analog ground |

Pin 4 `EXTCOMIN` is the net the schematic punch list assigns to PA8 —
see [`docs/schematic-fixes.md`](../../docs/schematic-fixes.md) item 4.
`EXTMODE` (pin 8) must be tied high for that hardware-driven toggle to do
anything; tied low, the COM inversion flag comes over the serial link instead.

## Regenerating

```sh
pip install cadquery
python3 ls027b7dh01.py
```

Every dimension is a named constant at the top of the script, so if you need a
worst-case-tolerance variant for clearance checking, edit the constants and
re-run.
